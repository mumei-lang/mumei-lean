# mumei-lean Claude Code Guide

## Overview

`mumei-lean` is the external Lean 4 proof backend for Mumei. Mumei first tries to prove `.mm` contracts automatically with Z3; when a proof certificate marks atoms as `unknown`, this repository translates those obligations into Lean 4 theorems, runs Lake, and emits `.lean-cert.json` certificates that Mumei can consume.

This repository currently has no MCP server. Use the CLI and Python scripts directly.

## Build

The Lean toolchain is pinned in `lean-toolchain`; install it with `elan`:

```bash
elan toolchain install $(cat lean-toolchain)
```

Build the Lean libraries:

```bash
mkdir -p generated/Generated
lake build
```

## Bridge Workflow

The human-facing entrypoint is `scripts/bridge.py`.

Single certificate:

```bash
python scripts/bridge.py \
  --cert /path/to/module.proof-cert.json \
  --lean-cert-out out/module.lean-cert.json
```

Proof bundle:

```bash
python scripts/bridge.py \
  --bundle /path/to/std-proof-bundle.json \
  --lean-cert-out out/
```

Bulk scan a Mumei checkout for unknown atoms:

```bash
python scripts/bridge.py \
  --scan-unknown /path/to/mumei \
  --lean-cert-out out/ \
  --summary-json out/summary.json
```

Dry-run without Lake:

```bash
python scripts/bridge.py \
  --scan-unknown /path/to/mumei \
  --lean-cert-out out/ \
  --no-build
```

Pipeline:

1. Read a `.proof-cert.json` or proof bundle.
2. Collect atoms whose `z3_check_result` is `unknown`.
3. Generate Lean theorem files under `generated/`.
4. Run `lake build`.
5. Export `.lean-cert.json` with successful atoms marked `z3_check_result = "lean_verified"`.

## Tests

Run Python bridge tests:

```bash
PYTHONPATH=scripts MUMEI_LEAN_SKIP_LIVE=1 python -m pytest -q
```

Run live Lean-backed checks when the toolchain is ready:

```bash
unset MUMEI_LEAN_SKIP_LIVE
PYTHONPATH=scripts python -m pytest -q
lake build
```

## Key Files

| Path | Purpose |
| --- | --- |
| `scripts/bridge.py` | End-to-end `.proof-cert.json` → Lean → `.lean-cert.json` orchestrator. |
| `scripts/ingest_cert.py` | Converts unknown Mumei atoms into generated Lean theorem modules. |
| `scripts/export_cert.py` | Converts Lake build results into Mumei-compatible Lean certificates. |
| `scripts/expr_translator.py` | Translates Mumei contract expressions to Lean propositions. |
| `MumeiLean/` | Core Lean definitions, tactics, and pilot proofs. |
| `generated/` | Generated Lean theorem namespace; regenerated by bridge runs. |

## Certificate Semantics

- Input certificates come from `mumei verify --proof-cert`.
- Lean-successful atoms are emitted with `z3_check_result = "lean_verified"` and `status = "verified"`.
- Unproved atoms remain unchanged in the exported certificate.
- Mumei consumers must opt into Lean-backed certificates where required, e.g. with `--allow-lean-verified`.
